# 수업 운영 안내

## 수업 전날
- [ ] 교사 PC에서 `배포주소/check` 실행 → 모두 "통과"
- [ ] 학생 태블릿 4대에서 `배포주소`가 열리는지 확인 (학교 무선망이 Firebase를 막지 않는지)
- [ ] 태블릿 화면 자동 꺼짐 시간을 길게 (수업 중 잠기면 다시 켤 때 이어지긴 하지만 시간이 걸림)
- [ ] 개인 학습지 인쇄 (1차 결과 분석, 2차 생산 계획, 결과 비교, 최종 정리)

## 수업 시작 5분 전
1. 교사 PC에서 `배포주소/teacher` → 구글 로그인 → **새 수업 방 만들기**
2. 화면의 입장 코드(다섯 글자)를 칠판·프로젝터에 띄움
3. 모둠 태블릿에서 `배포주소` 열기 → 입장 코드 입력 → 모둠 나라 고르기 (확인 창에서 한 번 더 확인)
4. 교사 화면 **수업 방 · 접속 현황**에서 네 나라 모두 "접속 중"인지 확인
5. 프로젝터에는 위쪽 **발표 화면** 탭 → [전체 화면]

> 학생 주소는 `배포주소/?room=입장코드` 형태로 바로 열 수도 있습니다. 교사 화면의 [주소 복사]를 이용하세요.

## 수업 중 단계 진행 (교사 화면 [다음 단계 ▶])

| 단계 | 학생 화면 | 시간 |
|---|---|---|
| 1 대기·국가 정보 | 생산 수준과 생산량 비교표 | 도입 5분 |
| 2 1차 생산 | 생산 버튼 (무역 없음) | 8분 |
| 3 1차 결과 분석 | 결과 그래프 + 학습지 질문 | 5분 |
| 4 2차 계획 | 계획 질문 + 1차 결과 (이때 1차 기록 저장, 창고 초기화) | 2차 10분 |
| 5 2차 생산 | 생산 버튼 | |
| 6 무역 | 거래 제안·수락 + 남은 생산 | |
| 7 결과 비교 | 1차·2차 비교, 무역 흐름, 학습지 질문 | 8분 |
| 8 최종 정리 | 학습지 정리 + 모형의 한계 안내 | 4분 |

학생은 교사가 단계를 바꾸기 전에는 다음 단계로 갈 수 없습니다. 3→4단계로 넘어갈 때만 확인 창이 한 번 뜹니다.

## 예외 상황 대응

| 상황 | 어떻게 되나 | 교사가 할 일 |
|---|---|---|
| 학생이 새로고침 | 같은 나라, 같은 진행 상황으로 바로 돌아옴 | 없음 |
| 태블릿 화면이 꺼졌다 켜짐 | 자동 재연결, 그대로 이어짐 | 없음 |
| 인터넷이 잠깐 끊김 | 화면 위에 주황색 "연결이 끊겼어요" 띠. 그동안 누른 생산·거래는 "인터넷 연결을 확인하고 다시 눌러 주세요" 안내, 저장 안 됨 | 연결되면 다시 누르게 함 |
| 생산 버튼 여러 번 빠르게 누름 | 한 번 처리될 때까지 다음 누름은 무시 | 없음 |
| 실수로 잘못 생산 | 학생 화면 [마지막 생산 되돌리기] (같은 차수 안에서, 무역에 안 쓴 물품만) | 공정성이 필요하면 [학생 되돌리기 허용] 끄기 |
| 두 모둠이 같은 재고로 동시에 거래 | 먼저 처리된 하나만 성립, 다른 쪽은 "창고에 물품이 부족해서" 안내 | 없음 |
| 거래를 잘못 성립시킴 | — | 교사 화면 거래 기록 → [거래 취소] (물품이 아직 남아 있을 때) |
| 단계를 바꾸는 순간 학생이 거래 | 서버가 거부, 남은 제안은 "단계 변경으로 무효" | 필요하면 6단계로 되돌림 |
| 모둠이 다른 나라를 잘못 고름 | 기기가 그 나라로 고정됨 | 접속 현황에서 [자리 비우기] → 다시 고르게 함 (창고는 그대로) |
| 태블릿 고장·배터리 방전 | — | 다른 기기에서 입장 → 교사가 [자리 비우기] 후 그 나라 선택. 급하면 교사 화면 위쪽 나라 탭에서 교사가 대신 조작 |
| 실수로 단계를 너무 넘김 | — | [◀ 이전 단계]. 단, 2차에서 1차로 돌아가면 2차 진행이 지워짐 |
| 처음부터 다시 | — | [게임 전체 초기화] (학생 접속은 유지) |
| 학교 인터넷 전체 불가 | — | `배포주소/demo` 시연 모드를 교사 PC에서 프로젝터로 띄워 모둠 대표가 나와 조작 |

## 수업 후
교사 화면 [다른 방 열기] → [지난 방 모두 지우기]로 기록을 정리할 수 있습니다. 지우지 않아도 무료 사용량에는 영향이 거의 없습니다.
